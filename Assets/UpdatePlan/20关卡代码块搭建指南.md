# 20 关卡代码块搭建指南

> 基于 `Assets/LevelDate/Level 1~20.asset`。**全部关卡网格均为 10×10**。  
> 本文说明每关如何用现有 Prefab **拼块、连线、运行**以收集全部星星。

---

## 0. 搭建前须知

### 代码块清单

| 类型 | Prefab | 作用 |
|------|--------|------|
| 入口 | `Start` | 程序起点，所有块链从这里开始 |
| 动作 | `MoveForward` | 沿当前朝向走 1 格 |
| 动作 | `TurnLeft` / `TurnRight` | 原地左转 / 右转 90° |
| 循环 | `While` + `WhileEnd` | 条件为真时重复执行中间块 |
| 分支 | `IF` + `IfEnd`（可选 `Else`） | 条件为真走 If 体，为假跳 Else 或 IfEnd |
| 条件 | `DetectFrontStar` | 正前方 1 格有**下一颗**待捡星 → true |
| 条件 | `DetectLeftStar` / `DetectRightStar` | 左 / 右 1 格同理 |
| 条件 | `StarRemain` | 场上还有未捡星 → true |

### VR 连线方式

1. **顺序链（黄色）**：右扳机选中块 A → 再选中块 B → A.next = B  
2. **条件链（绿色 Judger）**：选中 `While` 或 `IF` → 再选中 Bool 块 → 作为条件  
3. **运行**：左扳机执行；校验失败会在状态栏提示（如 While 缺 Judger）

### 坐标约定

- `(x, y)`：x 向东增，y 向北增；起点 `(0,0)` 在网格左下角  
- 朝向：`0=北 1=东 2=南 3=西`  
- 星星**必须按 `starPositions` 数组顺序**经过，碰到的即收集，无需单独「捡星」块

## Level 1 — 第一次前进

**关卡数据**

| 字段 | 值 |
|------|-----|
| 网格 | 10×10 |
| 起点 / 朝向 | (0,0) 朝东 |
| 星星 | (2,0) × 1 |

**地图**

```
y=0:  R → → ★
      0  1  2
```

**教学目标**：理解「程序从上到下执行」；`Start` 连 `MoveForward` 即可驱动机器人。

**走法**：向东走 2 格到 (2,0) 捡星。

**搭建步骤**

1. 从场景拿 `Start` 和 2 个 `MoveForward`  
2. 右扳机：`Start` → 第一个 `MoveForward` → 第二个 `MoveForward`（黄线串联）  
3. 左扳机运行

**参考程序**

```
Start → MoveForward → MoveForward
```

**本关块池**：Start、MoveForward

## Level 8 — 直线重复（循环入门）

**关卡数据**

| 字段 | 值 |
|------|-----|
| 网格 | 10×10 |
| 起点 / 朝向 | (0,3) 朝东 |
| 星星 | (1,3)~(6,3) 共 6 颗 |

**地图**

```
y=3:  R → ★ ★ ★ ★ ★ ★
      0  1  2  3  4  5  6
```

**教学目标**：相同动作重复 6 次 → 引入 `While`，避免手动连 6 个 Move。

**搭建步骤**

1. 拿 `Start`、`While`、`WhileEnd`、`StarRemain`、`MoveForward`  
2. 顺序链：`Start → While → MoveForward → WhileEnd`  
3. **绿线**：`While` ← `StarRemain`（Judger）  
4. 左扳机运行：只要还有星，就 Move 一次

**参考程序**

```
Start → While(StarRemain)
          → MoveForward
        WhileEnd
```

**解法 B（展开）**：6 个 MoveForward 串联，效果相同但块多。

y=1:           ★④ ★⑤

```

      → MoveForward
    Else

    IfEnd

**参考程序**

```

        WhileEnd

## 附录 C：常见问题

1. **Wrong Order!** — 星星顺序错了；检查 `starPositions` 与路径是否一致。  
2. **While/If missing condition** — 忘记用绿线连 Judger。  
3. **StarFront 为 false** — 星不在正前方 1 格；需 Turn 或改用 StarLeft/StarRight。  
4. **Move 没动** — 目标格越界，Move 会静默跳过。
