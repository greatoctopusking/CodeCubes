# 关卡系统与离散移动重构方案

## 1. 概述

为 VR 编程游戏添加关卡系统，引入离散网格移动、转向代码块、星星检测布尔块，以及关卡管理模块。

---

## 2. 新增代码块（5 个）

### 2.1 TurnLeftCode / TurnRightCode

```
TurnLeftCode : Code
  work(): RobotTarget.Rotate(0, -90, 0); Complete();

TurnRightCode : Code
  work(): RobotTarget.Rotate(0, 90, 0); Complete();
```

### 2.2 StarFrontCode / StarLeftCode / StarRightCode

```
StarFrontCode : BoolCode
  work(): 扫描 Star[]，检查 robot.position + robot.forward * cellSize
          范围内是否有 orderIndex == LevelManager.nextStarIndex 的未收集星星
          → judge = true/false; Complete();

StarLeftCode : BoolCode
  同上，方向 = Quaternion.Euler(0, -90, 0) * robot.forward

StarRightCode : BoolCode
  同上，方向 = Quaternion.Euler(0, 90, 0) * robot.forward
```

## 4. 关卡模块（4 个文件）

### 4.1 LevelData.cs（ScriptableObject）

```csharp
[CreateAssetMenu(fileName = "Level", menuName = "VRPG/Level Data")]
public class LevelData : ScriptableObject
{
    public Vector2Int gridSize = new(10, 10);
    public Vector2Int robotStart;
    public RobotDirection robotFacing;
    public Vector2Int[] starPositions;  // 按收集顺序
}

public enum RobotDirection { North, East, South, West }
```

### 4.2 Star.cs

```csharp
public class Star : MonoBehaviour
{
    public int orderIndex;
    public bool collected;
    
    public void Collect()
    {
        collected = true;
        gameObject.SetActive(false);
    }
}
```

### 4.3 StarCollector.cs（挂在 Robot 上）

```csharp
public class StarCollector : MonoBehaviour
{
    void OnTriggerEnter(Collider other)
    {
        if (other.TryGetComponent<Star>(out var star) && !star.collected)
            LevelManager.Instance.CollectStar(star);
    }
}
```

### 4.4 LevelManager.cs

#### 职责
- 单例，管理关卡生命周期
- 读取 `LevelData[] levels`（Inspector 拖入 .asset 文件）
- 生成/销毁网格 Tile
- 生成/销毁星星
- 放置机器人
- 顺序收集检测
- 通关/重置

#### 网格生成

```
GenerateGrid():
  cellSize = 1f
  offset = -gridSize / 2
  遍历 (x, y):
    place = offset + (x + 0.5, 0, y + 0.5)
    棋盘着色：(x+y) % 2 → 两种颜色 Tile
    Instantiate(tilePrefab, place, parent=gridParent)
```

#### 坐标转换

```csharp
Vector3 CellToWorld(Vector2Int cell) =>
    new Vector3(offset.x + cell.x + 0.5f, yHeight, offset.z + cell.y + 0.5f);
```

#### 核心流程

```
Start() → LoadLevel(0)

LoadLevel(i):
  销毁旧 grid / stars
  生成网格 → 放机器人 → 放星星
  nextStarIndex = 0

CollectStar(star):
  if star.orderIndex != nextStarIndex → RestartLevel()
  star.Collect()
  nextStarIndex++
  if all done → screen.UpdateText("Level Complete!"), 延时后 LoadLevel(i+1)

RestartLevel() → LoadLevel(currentIndex)
```
