# 5.8 代码块连接重构方案

## 1. 概述

将现有「物理碰撞吸附」连接方式替换为「射线指向连接」方式。消除因父子关系重设、isKinematic 切换、collider ignore 等操作引发的 bug，提升操作精确度。

## 2. 当前问题

- 代码块需物理移动到另一个块的 DetectCollider 范围内才能触发连接，精度差、容易误连
- 连接时大量修改 Transform parent、Rigidbody kinematic、Collider ignore，状态复杂难追踪
- 多种 DetectCollider 变体（5个）逻辑高度重复，维护困难

## 3. 新交互流程

```
[空闲] ──右扳机(Activate)按下 + 射线命中MoveCode块A──▶ [选中A]
  ├── A 变蓝色高亮
  ├── 显示预览箭头：A右侧输出端 → 右手柄射线终点（带三角锥箭头）
  │
  ├── 右扳机 + 命中另一个MoveCode块B ──▶ 连接 A.next = B，回到空闲
  ├── 右扳机 + 命中A自身            ──▶ 断开 A.next = null，回到空闲
  └── 右扳机 + 命中空白             ──▶ 取消选中，回到空闲
```

> 本次重构仅实现 MoveCode 的 `next` 连接。IfCode / WhileCode 的多槽位（Judger、LoopNext、NoBreakNext、BreakNext）暂不处理。

## 5. 模块设计

### 5.1 Code.cs 修改

```csharp
// 新增虚方法，返回连线端点世界坐标
public virtual Vector3 GetOutputPoint()
{
    return transform.position + transform.right * 0.5f;
}

public virtual Vector3 GetInputPoint()
{
    return transform.position - transform.right * 0.5f;
}
```

### 5.2 CodeManager.cs 修改

```csharp
// 新增公开属性，供 ConnectionManager 在执行期间禁用连接
public bool IsExecuting => playRoutine != null;
```

### 5.3 ConnectionManager.cs

#### 职责
- 监听右手柄 Activate 动作（右扳机）
- 从 `XRI Right Interaction` map 获取 `Activate` action
- 执行射线检测
- 管理 `selectedBlock` 状态与视觉高亮
- 创建 / 销毁预览箭头
- 创建 / 销毁 / 刷新固定连线
- 连接 / 断开时管理目标块的物理状态

#### 核心字段

| 字段 | 类型 | 说明 |
|------|------|------|
| inputActions | InputActionAsset | 输入动作资产 |
| rightController | Transform | 右手柄 Transform，射线起点 |
| previewLineMaterial | Material | 预览箭头线条材质 |
| connectionLineMaterial | Material | 固定连线线条材质 |
| selectedBlock | Code | 当前选中的代码块 |
| connections | List\<ConnectionData\> | 所有活动连接的数据 |
| previewLine | LineRenderer | 动态预览线条 |
| previewArrowhead | GameObject | 预览箭头末端三角锥 |

#### 核心逻辑

```
HandleActivateDown():
  射线检测 → hitBlock
  
  if selectedBlock == null:
    if hitBlock is MoveCode:
      SelectBlock(hitBlock)
  else:
    if hitBlock is MoveCode && hitBlock != selectedBlock:
      if TryConnect(selectedBlock, hitBlock):
        Connect(selectedBlock, hitBlock)
    else if hitBlock == selectedBlock:
      Disconnect(selectedBlock)
    DeselectBlock()
```

#### 连接验证规则 (TryConnect)

1. 目标和来源不是同一个块
2. 遍历目标块的 `next` 链表，不形成环形引用
3. 目标块不能已是其他块的 `next`（通过扫描所有 MoveCode 判断）
4. CodeManager 不在执行状态

#### 连接建立 (Connect)

1. 断开 from 的旧 next（Disconnect(from)）
2. 设置 from.next = to
3. 设置 to.GetComponent\<Rigidbody\>().isKinematic = true
4. 创建 ConnectionData，记录 LineRenderer + 箭头
5. 固定连线起点为 from.GetOutputPoint()，终点为 to.GetInputPoint()

#### 连接断开 (Disconnect)

1. 清除 from.next
2. 若旧目标不再被任何块指向，恢复 isKinematic = false
3. 移除对应的 ConnectionData 和视觉连线

#### Update 循环

- 若 selectedBlock 非空：更新预览线的起点（selectedBlock.GetOutputPoint()）、终点（射线碰撞点），更新预览箭头位置和朝向
- 遍历所有 connections：调用 LineRenderer.SetPosition 同步端点

### 5.4 ArrowheadGenerator.cs

运行时创建简易三角锥 mesh（顶点朝前），挂载到 GameObject 上，作为箭头末端。

## 6. 物理规则

| 状态 | Rigidbody 设置 |
|------|----------------|
| 块未被任何块指向 | isKinematic = false, useGravity = true |
| 块被连接为某块的 next | isKinematic = true, useGravity = false |
| 仍可通过 XRGrabInteractable 抓取移动 | 不受影响 |

## 7. 视觉规范

| 元素 | 颜色 | 材质 |
|------|------|------|
| 选中高亮 | 蓝色 | 块 Renderer.material.color |
| 预览箭头 | 淡蓝半透明 | LineRenderer + 三角锥 |
| 固定连线 | 黄色 | LineRenderer + 三角锥 |
| 执行中高亮 | 黄色（保持原有逻辑） | Code.SetHighlight |

连线宽度：0.02。预览线使用虚线或更低透明度以示区别。

## 8. 边界情况处理

| 场景 | 行为 |
|------|------|
| 选中块 + 右手柄扳机抓起移动 | 正常抓取，选中箭头随块位置实时更新 |
| 代码正在执行时按下 Grip | 拒绝所有连接/断开操作，可加 Debug.Log 提示 |
| 射线同时命中多个块 | 取最近的 RaycastHit |
| 场景中无任何 MoveCode 块 | 按 Grip 无反应 |
| 块的 Rigidbody 组件缺失 | 跳过物理状态修改，只建立连接引用 |
