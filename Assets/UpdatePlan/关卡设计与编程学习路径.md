# 关卡设计与编程学习路径

> 当前 **12 关**：`Assets/LevelDate/Level 1.asset`～`Level 12.asset`。  
> 网格一律 **10×10**。坐标：`x` 向东、`y` 向北；朝向 `0=北 1=东 2=南 3=西`。  
> 走到星星所在格即收集，无需单独的「捡星」块。

---

## 1. 设计原则

关卡按入门编程的概念递进，而不是越来越难的迷宫：

1. **顺序**：一步一步写出路径  
2. **循环**：重复的事先写成「条件为真就再做」  
3. **分支**：有的动作只在条件成立时做  
4. **组合**：循环负责走下去，分支负责在拐角做决定  

每一关墙上只能抓取大屏幕上的 **Suggested Blocks**。教学关还会限制移动块数量，避免用一长串 `MoveForward` 绕过循环/分支。

| 关卡 | 墙上策略 | 目的 |
|------|----------|------|
| 1–5 顺序 | 只放本关动作块，数量按 Catalog | 学会拼程序、规划路径 |
| 6–9 结构教学 | 每种移动块只放 **1** 个；`While`/`IF` 最多 2 套 | 必须复用结构 |
| 10–12 综合 | 完整工具集；每种移动块最多 **4** 个 | 长路径必须循环；允许多种解 |

Level 7 在运行前会检查程序里必须出现 `IF`（单星在左时，`TurnLeft + MoveForward` 物理上也能走通，但本关要练的是条件判断）。

`True` / `False` 不进入任何关卡，避免 `While True` 一类投机解。

---

## 2. 积木与编程概念

| 积木 | 概念 |
|------|------|
| `Start` → 下一块 | 程序从入口顺序执行 |
| `MoveForward` | 语句 / 基本动作 |
| `TurnLeft` / `TurnRight` | 改变状态后再继续 |
| `While` + 条件 + `WhileEnd` | 循环 |
| `IF` + 条件 + `IfEnd`（可选 `Else`） | 分支 |
| `DetectFrontStar` / `DetectLeftStar` / `DetectRightStar` | 看一格的布尔条件 |
| `StarRemain` | 场上是否还有星 |

顺序链用黄线（`next`）；条件挂在 `While` / `IF` 上用绿线（`Judger`）。

阶段 C  策略        Level 10–12   完整工具：阶梯、矩形、螺旋

## 4. 分关说明

图例：`R` 机器人，箭头为初始朝向，`★` 星星，`.` 空格。

### Level 1 — 第一次前进

| | |
|---|---|
| 起点 / 朝向 | (0,0) 东 |
| 星星 | (1,0) |
| 墙上 | Start, MoveForward |

```
y=0:  R→ ★
      0  1
```

**教什么**：程序按连接顺序执行；一块前进 = 走一格。

```
Start → MoveForward
```

---

### Level 2 — 第一次转向

| | |
|---|---|
| 起点 / 朝向 | (0,0) 东 |
| 星星 | (0,1) |
| 墙上 | Start, MoveForward, TurnLeft |

```
y=1:  ★
y=0:  R→
      0
```

**教什么**：朝向是状态；要先转向再前进。本关只给左转。

```
Start → TurnLeft → MoveForward
```

---

### Level 3 — 前进与转向组合

| | |
|---|---|
| 起点 / 朝向 | (0,0) 东 |
| 星星 | (2,1) |
| 墙上 | Start, MoveForward, TurnLeft, TurnRight |

```
y=1:        ★
y=0:  R→ .  .
      0  1  2
```

**教什么**：一条路径可以有多种写法；开始同时提供左右转。

```
Start → MoveForward → MoveForward → TurnLeft → MoveForward
```

---

### Level 4 — 多星 U 形

| | |
|---|---|
| 起点 / 朝向 | (0,0) 东 |
| 星星 | (2,0), (2,2), (0,2) |
| 墙上 | Start, MoveForward, TurnLeft, TurnRight |

```
y=2:  ★  .  ★
y=1:  .  .  .
y=0:  R→ .  ★
      0  1  2
```

**教什么**：连续收集多颗星；同一动作可以重复摆放。两次左转沿 U 走完。

```
Start → MF → MF → TurnLeft → MF → MF → TurnLeft → MF → MF
```

---

### Level 5 — 折线 + 一阶

| | |
|---|---|
| 起点 / 朝向 | (0,0) 东 |
| 星星 | (1,0), (1,2), (3,2), (4,3) |
| 墙上 | Start, MoveForward, TurnLeft, TurnRight |

```
y=3:              ★
y=2:     ★  .  ★
y=1:     .
y=0:  R→ ★
      0  1  2  3  4
```

**教什么**：顺序关收束。折线要切换左右转，最后一颗是阶梯步。路径变长，为循环做铺垫。

走法：东 1 → 左转北 2 → 右转东 2 → 左转北 1 → 右转东 1。

---

### Level 6 — 第一次循环：还有星就走

| | |
|---|---|
| 起点 / 朝向 | (0,0) 东 |
| 星星 | (1,0)～(6,0) 共 6 颗 |
| 墙上 | Start, MoveForward, While, WhileEnd, StarRemain |
| 数量 | 仅 1 个 MoveForward，不能摆 6 次前进 |

```
y=0:  R→ ★ ★ ★ ★ ★ ★
      0  1 2 3 4 5 6
```

**教什么**：循环。条件是 **场上是否还有星**，不看眼前那一格。循环体里复用同一块前进。

```
Start → While (StarRemain)
            MoveForward
        WhileEnd
```

---

### Level 7 — 第一次分支：左边有星吗

| | |
|---|---|
| 起点 / 朝向 | (2,0) **北** |
| 星星 | (1,0)（在机器人左侧） |
| 墙上 | Start, MoveForward, TurnLeft, IF, IfEnd, DetectLeftStar |
| 校验 | 程序中必须包含 IF |

```
y=0:  ★  R↑
      1  2
```

**教什么**：`IF` + 传感器。朝北时左方是西。先判断再转向，再前进。本关不给 `While`。

```
Start → IF (DetectLeftStar)
            TurnLeft
        IfEnd
        → MoveForward
```

---

### Level 8 — 用「前方有星」控制循环

| | |
|---|---|
| 起点 / 朝向 | (0,0) 东 |
| 星星 | 与 Level 6 **同一条直线**：(1,0)～(6,0) |
| 墙上 | Start, MoveForward, While, WhileEnd, DetectFrontStar |
| 数量 | 仅 1 个 MoveForward |

```
y=0:  R→ ★ ★ ★ ★ ★ ★
      0  1 2 3 4 5 6
```

**教什么**：同一张图、同一种循环，只换条件。Level 6 看全场（`StarRemain`），本关看 **正前方一格**（`DetectFrontStar`）。走到 (6,0) 后前方无星，循环自然结束。

```
Start → While (DetectFrontStar)
            MoveForward
        WhileEnd
```

---

### Level 9 — 循环里转弯（连续 L）

| | |
|---|---|
| 起点 / 朝向 | (0,0) 东 |
| 星星 | (1,0)～(5,0)，再 (5,1)～(5,5)，共 10 颗 |
| 墙上 | Start, MoveForward, TurnLeft, While, WhileEnd, DetectFrontStar |
| 数量 | 2 个 MoveForward、2 个 DetectFrontStar、2 套 While（两段循环各用一套，不能共用同一块） |

```
y=5:              ★
y=4:              ★
y=3:              ★
y=2:              ★
y=1:              ★
y=0:  R→ ★ ★ ★ ★ ★
      0  1 2 3 4  5
```

**教什么**：把 Level 8 的循环接两段，中间插一次左转。每段 While 需要自己的 `DetectFrontStar` 和 `MoveForward`（一块积木只能出现在链条的一个位置）。

**黄线（顺序）**

```
Start → While → MoveForward → WhileEnd → TurnLeft → While → MoveForward → WhileEnd
```

**绿线（条件）**：第一段 While ← DetectFrontStar；第二段 While ← 另一块 DetectFrontStar。

---

### Level 10 — 阶梯：循环 + 分支 + 左右探测

| | |
|---|---|
| 起点 / 朝向 | (0,0) 东 |
| 星星 | (1,0),(2,0),(2,1),(3,1),(3,2),(4,2),(4,3),(5,3) |
| 墙上 | 完整工具集 |
| 数量 | 每种移动块最多 4 个（8 步阶梯不能纯顺序铺完） |

```
y=3:                 ★
y=2:              ★  ★
y=1:           ★  ★
y=0:  R→ ★  ★
      0  1  2  3  4  5
```

**教什么**：第一次给出完整工具（含 `Else` 与三个方向探测）。转角有时在左、有时在右。

游戏里**没有 elif 块**。做法是：外层 `IF / Else`，在 Else 分支里再嵌一套 `IF / Else`。

策略：还有星就继续；前方有星就走；否则看左边有星就左转，不然右转。

**黄线（顺序）**

```
Start → While → IF → MoveForward → Else → IF → TurnLeft → Else → TurnRight → IfEnd → IfEnd → WhileEnd
```

**绿线（条件）**

- While ← StarRemain
- 外层 IF ← DetectFrontStar
- 内层 IF ← DetectLeftStar

`DetectRightStar` 本关可以不用（右转放在最后的 Else 里）。墙上有 **2 个 Else**（外层、内层各一个）。

---

### Level 11 — 稀疏矩形：定长重复

| | |
|---|---|
| 起点 / 朝向 | (0,0) 东 |
| 星星 | (4,0), (4,4), (0,4), (0,1) |
| 墙上 | 完整工具集 |
| 数量 | 每种移动块最多 4 个 |

```
y=4:  ★  .  .  .  ★
y=3:  .           .
y=2:  .           .
y=1:  ★           .
y=0:  R→ .  .  .  ★
      0  1  2  3  4
```

**教什么**：星不连续，起点前方无星，`DetectFrontStar` 开局为假。更自然的解是「每次前进 4 格再左转」，用 `StarRemain` 包住固定长度的边。最后一边到 (0,1) 只需 3 步，第 4 步走到起点空格，随后因无星结束。

```
Start → While (StarRemain)
            MoveForward × 4
            TurnLeft
        WhileEnd
```

---

### Level 12 — 毕业：向内螺旋

| | |
|---|---|
| 起点 / 朝向 | (0,0) 东 |
| 星星 | 23 颗：东到 (6,0) → 北到 (6,5) → 西到 (1,5) → 南到 (1,2) → 东到 (4,2) → 北到 (4,3) |
| 墙上 | 完整工具集 |
| 数量 | 每种移动块最多 4 个（远少于 23 步，必须循环） |

```
      0  1  2  3  4  5  6
y=5      ★  ★  ★  ★  ★  ★
y=4      ★              ★
y=3      ★        ★     ★
y=2      ★  ★  ★  ★     ★
y=1                     ★
y=0   R→ ★  ★  ★  ★  ★  ★
```

**教什么**：综合运用循环、分支和三个方向的探测，跟着星星走，而不是背 23 步脚本。前方无星时，用左右探测决定转向。

参考策略与 Level 10 相同：`StarRemain` + 前方走 / 否则朝有星的一侧转。

---

## 5. 学习路径（给学生的四句话）

1. **1–5**：我会让机器人按我想的顺序走。  
2. **6 和 8**：重复的事先写成循环；条件可以是「还有星」或「前面有星」（同一条直线，只换条件）。  
3. **7**：有的动作只在条件成立时做。  
4. **9–12**：循环负责走下去，转弯和分支负责在拐角做决定。
